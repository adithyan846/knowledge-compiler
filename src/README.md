# Knowledge Compiler

A deterministic compiler that transforms engineering Markdown documents into structured knowledge units.

## Features

- Markdown parser
- Knowledge extraction
- Fragmentation
- Rule-based analysis
- Knowledge interpretation
- Schema resolution
- Validation
- YAML generation
- Knowledge indexing

## Pipeline

Markdown
→ Parser
→ Extractor
→ Fragmenter
→ Analyzer
→ Interpreter
→ Schema Resolver
→ Validator
→ Writer
→ Indexer
